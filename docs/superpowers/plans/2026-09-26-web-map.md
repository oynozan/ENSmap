# ENSmap Web Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plain dark web page. You type a Sepolia ENSv2 name into a rounded search bar, and a d3-force bubble map of its subname tree and wallets fills the rest of the page. Clicking a bubble opens a slim details panel.

**Architecture:**

- **Core.** `packages/core` gains two server-side modules and one browser-safe module:
  - `pipeline`, which loads a name map from env; the CLI and the API share it.
  - `graph`, which builds the Phase 4 graph from a name map.
  - `schema`, the zod graph and API-error contract, which the browser may import.
- **API.** `apps/api` serves `GET /map/name/:name` through a cached `MapService`.
- **Web.** `apps/web` (Vite and React) renders the map:
  - d3-force runs in a Web Worker;
  - drawing is canvas 2D with d3-zoom;
  - React handles the search bar, panel, status line and keyboard node list.

**Tech Stack:** TypeScript 6 strict, React 19.3, Vite 8.3, d3-force 3.0.0, d3-zoom 3.0.0, d3-selection 3.0.0, zod 4.6, Hono 4.13, Vitest 5 with jsdom 30.1.1 and @testing-library/react 16.3.3, playwright-core 1.63.0 driving the installed Chrome, @fontsource-variable/lexend-deca 5.3.0 and @fontsource-variable/manrope 5.3.0.

**Spec:** `docs/superpowers/specs/2026-09-26-web-map-design.md` (read it first; this plan argues from it). Project spec: `docs/spec.md`.

## Review Focus

1. **A new search while an older one is still loading.** The older response must never replace the newer map. Pinned in Task 6: `App.test.tsx` "ignores a stale response".
2. **A lookup against a slow or rate-limited source.** The keyless source retries for minutes. The page must stay busy and then show a clear error, never hang. Pinned in Task 5: `api.test.ts` "times out".
3. **Pasted names with uppercase, emoji or bad characters.** `Seller-A.eth` must load `seller-a.eth` and share its cache entry. `❤.eth` must be URL-encoded and decoded. `a_b.eth` must show its label reason. Pinned in Task 3 (`app.test.ts` normalization and encoding cases) and in Task 5 (`api.test.ts` encoding).
4. **Deep links and Back/Forward.** Opening `?name=gloomy.eth` loads the map, and Back restores the previous name. Pinned in Task 6: `App.test.tsx` "loads ?name= on mount" and "re-runs on popstate".
5. **Odd trees.** Covers a node inside its own registry (a self-parent), a root with no children, and a 390 px phone screen. Expected: no self-loop edge, a sensible camera for a single bubble, and no horizontal scroll. Pinned in Task 1 (self-parent), Task 4 (`fitTransform` single node) and Task 6 (the screenshot script's scroll-width check).

**`buildGraph` rules (spec §2):**

- **Order.** Nodes follow `tree.nodes` insertion order, which is BFS. Edges are sorted by `id` in code-unit order.
- **`label`** is `beautifyName(node.name)`.
- **`kind`** is `'name'` if the id is `rootId` or any `wallets[*].homeNameId`, else `'subname'`.
- **Binding fields.** The node's binding (`bindings` by `nameId`) gives `address`, `verified`, `chainId` and, when non-null, `verifiedBy`.
- **Wallet fields.** `homeName` is the group's `homeNameId`. `names` is `[homeNameId, …memberNameIds without the home]`. Both are set only when there is an `address`.
- **`owner`** is `record.owner`, omitted when null.
- **`canonical`** is `beautifyName(record.canonicalName)`, only when the tags contain `alias-path`.
- **`sharedWith`** is `externalReferrers.get(id)` beautified, omitted when missing or empty.
- **`tags`** are the name map's tags, plus `self-parent` when `parentIds` includes the node's own id.
- **Edges.** One `{ id: 'subname:<parentId>:<childId>', source: parentId, target: childId, kind: 'subname', directed: true }` per parent id that is in the tree and differs from the node's id.
- **`size`** is `{ metric: 'subnamesHeld', value: <number of distinct nodes reachable through child edges, excluding the node itself> }`.
- **`meta`:**
  - `root` is `rootId`, and `computedAt` is the ISO form of `computedAt`.
  - `caps` is `{ fetch: fetchCap }`, and `filters` is `{}`.
  - `totals` is `{ names: tree.nodes.size, indexed: tree.indexedTotal, wallets: wallets.size }`.
  - `truncated` is `tree.truncated ? ['names'] : []`, and `warnings` is `r.warnings`.

  - `createCachedMapService(build: (namespace: NamespaceId, name: InterpretedName) => Promise<Graph>, opts: { ttlMs: number; maxEntries: number; now: () => number }): MapService`
    - The cache key is `` `${namespace}:${name}` ``.
    - In-flight builds are shared.
    - A rejected build is not stored.
    - Past `maxEntries`, the oldest entry is dropped.
  - `createLiveMapService(deps: { env: Env; fetch?: typeof fetch; sleep?: (ms: number) => Promise<void>; now?: () => number; log?: (line: string) => void }): MapService`
    - It wraps `resolveNamespace`, `loadNameMap` and `buildGraph` in the cache.
    - After each build it logs `map <namespace> <name> · <counter.format()>`, using `console.log` by default.
  - `toErrorResponse(error: unknown, secrets: readonly string[]): { status: 404 | 500 | 502; body: ApiError }`
    - `NameNotFoundError` gives 404 `not-found`, with the CLI's message text.
    - `ProviderError` gives 502 `provider-error`, with message `` `Provider ${provider} failed: ${message}` ``.
    - Anything else gives 500 `internal` with the message `Internal error`, and the redacted error is logged.
    - Messages are redacted.
  - `interface AppDeps { readonly env?: Env; readonly maps?: MapService; readonly log?: (line: string) => void }`. `createApp` builds a live service lazily when `maps` is absent.
  - **Route `GET /map/name/:name`:**
    - The `namespace` query defaults to `'mainnet'`. A value outside `mainnet | sepolia-v2` gives 400 `invalid-namespace` with message `Unknown namespace; use mainnet or sepolia-v2`, which doesn't echo the value.
    - The name comes from `parseNameInput(decoded param)`. On failure it gives 400 `invalid-name` with message `Invalid name` and the per-label errors in `labels`.
    - On success it returns `c.json(graph)`.
  - `server.ts` passes `{ env: loadEnv() }` and logs `ENSmap API on http://localhost:3000`.
